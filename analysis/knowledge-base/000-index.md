# Knowledge Base

This folder contains approved, durable project knowledge. It is not a task queue.

## Reading order

1. [`001-business-domain.md`](./001-business-domain.md) defines the approved business scope, vocabulary, rules, and acceptance scenarios.
2. [`../002-technical-plan.md`](../002-technical-plan.md) defines the approved technical direction.
3. [`../000-implementation-ladder.md`](../000-implementation-ladder.md) is the current implementation state and source-to-code map.

An AI or developer should read the ladder before treating any implementation plan as current. A plan can be approved without being implemented, and a code change can be uncommitted.

## Knowledge-base rule

Move a document here only when it records a stable decision or completed knowledge. Keep work plans, open questions, and execution checklists in `analysis/`.
